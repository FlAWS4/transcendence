# Relevés et captures du site avant la passe complète (18 octobre 2026)

Copie de `dom/` (relevés du DOM) et de `reference/` (captures du site) telles qu'elles étaient avant le relevé complet de la [passe complète](../../PASSE-COMPLETE.md). Ce relevé apporte :
- la composition GPU (flou du verre uniforme, comme sur un appareil) ;
- une horloge et un fuseau fixes (même heure dans toutes les variantes) ;
- le vrai globe, ancré dans la pastille « Monde » ;
- de nouveaux champs relevés : espaces insécables, couleur d'indication, curseur, isolation, soulignement, `resize`, bouts de trait ;
- les variantes qui manquaient.

Les cadres envoyés jusqu'au 18 octobre ont été construits depuis ces relevés-ci, qui servent aussi de référence pour les vérifications passées.
