# Couronne — état précédent du 11 octobre 2026

Sources ciblées conservées avant la demande de placer la couronne immédiatement à droite du nom, y compris dans l’interface arabe. Dans cet état, nom et couronne sont des enfants séparés du bloc de texte. Le rôle reste une ligne distincte.

Cette archive préserve les quatre sources actives concernées et le test auteurs avant modification ; ce n’est pas un aperçu autonome. Les autres sources, dépendances et archives du prototype restent à leur emplacement. Le manifeste indique les empreintes SHA-256 et la taille de chaque fichier copié.

Les six raccords de chargement précédents sont aussi conservés dans `raccords/` et recensés par le manifeste : entrées HTML, contrôleur, aperçu et imports Projet/Chroniques.
