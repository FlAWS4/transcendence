# Itinéraire pleine largeur — archive

[Ouvrir la fiche](preview.html) depuis le serveur local du projet.

Ce lecteur reconstitue la présentation avec le composant original «Itinéraire pleine largeur» et les données officielles Paris/Mulhouse figées le8octobre. Le snapshot initial ne contenait que le module et le CSS : cette association de données est explicitement une reconstitution, pas une preuve d’un état complet antérieur.

Les deux fichiers `campus-details.mjs` et `campus-details.css` restent les sources exactes. Les copies et dépendances nécessaires à la consultation se trouvent dans `runtime/`, avec provenance et empreintes dans `manifest.json`. Le lecteur propose Paris/Mulhouse, les trois langues et les thèmes après fermeture de la fiche. La lecture et les gestes sont ceux du composant conservé ; aucune carte n’est embarquée ici.

Polices, photos et logos partagés restent dans le prototype parent. Contrôles statiques réalisés ; aucun nouveau contrôle navigateur par cet agent.
