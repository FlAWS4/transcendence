# Compte — état avant les sous-panneaux dédiés du 13 octobre 2026

[Ouvrir le lecteur isolé](preview.html). Cliquer sur le compte puis **Thème** ou **Langue** reproduit le comportement remplacé : les deux groupes apparaissent ensemble. Le bouton de simulation permet aussi de voir les accès du membre fictif ; FR/EN/AR et les thèmes restent jouables.

Les quatre fichiers recensés par `source-manifest.json` sont les copies exactes prises avant modification : module, CSS, tests et notes. `runtime-originals/` garde également les sources HTML/JS/CSS/JSON de premier niveau capturées à cet instant ; ce dossier n’est pas un second aperçu complet. Le lecteur utilise le module/CSS archivés, les trois styles archivés et les tokens figés ici. Police Jost et avatar illustré sont partagés, inchangés par cette correction. Les callbacks de compte sont simulés, aucun stockage de l’aperçu actif n’est utilisé.

Demande explicite : **Thème** doit ouvrir les seuls modes de thème ; **Langue** les seules langues. **Paramètres** conserve les deux groupes. L’archive documente le comportement antérieur, sans approbation implicite.
