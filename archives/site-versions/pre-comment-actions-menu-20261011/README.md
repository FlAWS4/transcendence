# Comments before the owner actions menu

Source snapshot taken on 11 October 2026 before replacing the visible Edit and Delete buttons with one three-dot menu on locally owned comments and replies.

The snapshot preserves `comments.mjs`, `comments.css` and the existing pure model tests. Existing editing, mentions, replies, reactions and silent deletion are included. It is a source archive, not a standalone reader; the active prototype is at `../../../site/content-preview.html`. Earlier studies and archived readers remain unchanged.

`first-horizontal-pass-comments.mjs/css` preserve the initial, unverified implementation with horizontal dots before the explicit vertical-dot, reporting and sorting requirements. This intermediate pass was not browser-tested.
