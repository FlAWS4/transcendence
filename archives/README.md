# archives/ — earlier versions of the site

Nothing here is the current site (see [`site/`](../site/README.md)). Every folder is kept on purpose to document the research path; do not delete or overwrite it.

| Folder | Content |
| --- | --- |
| [`site-versions/`](site-versions/INDEX.md) | 159 preserved states of the active site, 5–18 October 2026, one folder per state, with an index of their dates, formats and entry pages. |
| [`site-b-versions/`](site-b-versions/README.md) | Preserved states of version B ([`site-b/`](../site-b/README.md), the Explorer without a globe), one folder per state. |
| [`early-prototypes/`](early-prototypes/README.md) | The first prototypes, built before or beside the active site: decryption, globe and explorer, content-first proposal, separate city map, panel-based welcome. |
